# UI/UX Pro Max skill bundle

Source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill (v2.13.0, MIT License, © Next Level Builder)

This directory vendors the project's `.claude/skills/` bundle directly from
the upstream repo so Claude Code picks it up automatically for this project.
It provides AI-powered design intelligence (UI styles, color palettes, font
pairings, UX guidelines, chart types, and design-token tooling) across the
following skills:

- `ui-ux-pro-max` — core searchable design-intelligence database (84 UI
  styles, 192 color palettes, 74 font pairings, 98 UX guidelines, 25 chart
  types across 22 tech stacks)
- `design-system` — token architecture, component specs, slide generation
- `ui-styling` — shadcn/ui + Tailwind CSS component styling, canvas designs
- `design` — brand identity, logos, corporate identity, icons, banners
- `brand` — brand voice, visual identity, messaging frameworks
- `banner-design` — social/ads/web/print banner design
- `slides` — strategic HTML presentations with Chart.js

To update, re-sync this directory from the upstream repo's `.claude/skills/`
folder and re-check the `LICENSE.txt` under `ui-styling/`.
